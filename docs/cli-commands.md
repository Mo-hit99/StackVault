# Command Line Tools

All commands are executed utilizing generic paths. You must ensure `gexra init` executes functionally establishing `.gexra/`.

## Local Tools
- **`gexra init`**: Instantiates a bare repository creating core metadata loops inherently.
- **`gexra commit -m "<msg>"`**: Stages generic buffers writing blob trees updating nodes correctly.
- **`gexra status`**: Tracks snapshot derivations yielding modified buffers interactively.
- **`gexra log`**: Enumerates linked chains backwards parsing metadata correctly.

## Remote Sync (Express)
- **`gexra remote add <origin> <url>`**: Mounts explicit paths handling base mapping seamlessly.
- **`gexra push origin main`**: Maps generic trees over HTTP natively skipping redundant blobs tracking chunks explicitly.
- **`gexra pull origin main`**: Restores chunks accurately matching backwards linking architectures seamlessly.
- **`gexra clone <url> [--path src]`**: Extrapolates missing trees parsing origin structures converting URLs smoothly mimicking paths safely.
