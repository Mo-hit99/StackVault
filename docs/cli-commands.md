# Command Line Tools

All commands are executed utilizing generic paths. You must ensure `sv init` executes functionally establishing `.stackvault/`.

## Local Tools
- **`sv init`**: Instantiates a bare repository creating core metadata loops inherently.
- **`sv commit -m "<msg>"`**: Stages generic buffers writing blob trees updating nodes correctly.
- **`sv status`**: Tracks snapshot derivations yielding modified buffers interactively.
- **`sv log`**: Enumerates linked chains backwards parsing metadata correctly.

## Remote Sync (Express)
- **`sv remote add <origin> <url>`**: Mounts explicit paths handling base mapping seamlessly.
- **`sv push origin main`**: Maps generic trees over HTTP natively skipping redundant blobs tracking chunks explicitly.
- **`sv pull origin main`**: Restores chunks accurately matching backwards linking architectures seamlessly.
- **`sv clone <url> [--path src]`**: Extrapolates missing trees parsing origin structures converting URLs smoothly mimicking paths safely.
